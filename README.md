# Data Science Fundamentals

This repository contains Python implementations of foundational data science algorithms, network metrics, and data analysis concepts from scratch.

## Contents
* **Social Network Analysis:** Degree centrality calculations and friend recommendation algorithms (finding friends of friends) using Python's `Counter` and dictionary structures.
* **Interest Matching:** Mapping user interests to recommend connections based on shared topics.
* **Salary & Experience Analysis:** Bucketing algorithms and exploratory analysis on tenure and income data.

## Technologies Used
* Python 3
* Built-in collections (`Counter`, `defaultdict`)
